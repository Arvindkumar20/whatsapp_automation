Instagram Module

Instagram Direct & Social Automation

Connect your Instagram Professional accounts to publish posts, manage Direct Messages in Team Inbox, and automate Comment-to-DM triggers.

01 Overview

The Instagram Module empowers businesses to connect their Instagram Business/Creator accounts with WhatsWay. It combines post scheduling, automated comment-to-DM response flows, and multi-agent Direct Message management inside Team Inbox.

Supported Features

instagram_dm comment_to_dm post_scheduling meta_webhooks

Key Features

  • Instagram Professional Account Integration
  • Meta App Credentials & Webhook Synchronization
  • Unified Team Inbox for Direct Messages
  • Keyword-Based Comment → DM Auto-Responders
  • Public Comment Auto-Reply with Custom Delays
  • Post Content Publishing & Scheduling
  • AI-Powered Caption & Content Generation
  • Real-time Delivery & Webhook Health Status

02 Account Connection

Superadmin App Setup

Superadmins configure the Meta Developer App once under platform settings so users can connect effortlessly.

Configuration Steps

  1. Navigate to Settings → Instagram
  2. Enter your Instagram App ID and App Secret
  3. Set the OAuth Redirect URI
  4. Define the Webhook Verify Token
  5. Copy the generated Webhook Callback URL and register it in Meta for Developers
  6. Subscribe to messages and comments events
User Channel Connection

Users connect their Instagram Business/Creator account via Meta OAuth login.

Connection Steps

  1. Open Social Media → Accounts
  2. Click Connect Instagram
  3. Authenticate with Facebook/Instagram credentials
  4. Select the target Instagram Professional account
  5. Verify connection status under Overview & Health tab

Only one Instagram account can be active per channel at a time. Disconnect the existing account before linking a new account.

03 Posts Management

Manage all visual media posts directly from the WhatsWay dashboard under Social Media → Posts.

  • Create & Schedule: Draft image posts, generate AI captions, and schedule publication times.
  • Status Filters: Easily view posts under All, Draft, Scheduled, Published, or Failed.
  • Live Feed Tracking: Monitor past published media with direct timestamps and account tags.

Target Keyword Matching (Fully Customizable)

Users can specify any custom keywords (comma-separated) in the Target Keywords input. The system supports flexible match options like Contains, Exact Match, or Starts With (Case Sensitive or Insensitive).

Common Keyword Examples

price cost link info buy discount interested details

05 Team Inbox Integration

All incoming Direct Messages appear seamlessly in the centralized Team Inbox alongside WhatsApp conversations.

Unified Conversation Filter
  • Dedicated Instagram Tab inside Team Inbox
  • Filter messages by status: Open, Pending, Resolved
  • Real-time message synchronization via Webhooks
Team Collaboration
  • Assign Instagram conversations to specific agents
  • Send image and text replies directly from dashboard
  • Pin important chats for priority handling

06 Webhook Events

The Instagram Module processes real-time events via Meta Webhook endpoints:

Event NamePurpose
messagesTriggers when a customer sends a Direct Message to your Instagram account
commentsDetects new comments on posts for Comment → DM automation
messaging_postbacksCaptures button taps and structured responses inside Direct Messages
messaging_seenTracks read receipts for outgoing messages in Team Inbox

07 Troubleshooting

IssueSolution
Account Connection FailedEnsure the Instagram account is converted to a Professional/Business account and linked to a Facebook Page.
Comment DM Not SendingVerify that Meta Webhooks are active and the exact keyword triggers are defined under Comment → DM settings.
Messages Not Showing in InboxCheck Webhook Verify Token in App Settings and verify Webhook Status in Social Accounts page.
Post Publishing FailedEnsure uploaded media respects Meta's supported aspect ratios and format guidelines.

Meta requires messages sent via Comment → DM automation to observe a 24-hour standard messaging window policy.

08 Conclusion

The Instagram Module simplifies social media engagement by combining post scheduling, Comment-to-DM auto-responders, and unified Team Inbox messaging into a single workflow. It allows businesses to turn casual Instagram post comments into direct sales conversations and active customer support leads.
